## Setup:

We recommend the use of a virtual environment. For example, with uv:

If you do not have `uv` installed, please install it from the [official uv website](https://docs.astral.sh/uv/getting-started/installation/).

```bash
uv venv
```

Then, activate .venv and install the required packages:
```bash
source .venv/bin/activate
uv pip install -r environment/requirements.txt
```
